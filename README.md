# EcoEdge-AI

This project aims to reduce the carbon footprint of AI systems by leveraging **Edge AI** and **renewable energy-powered data centers**. The system processes data locally on IoT devices, significantly lowering energy usage, and offloads heavy computations to cloud data centers powered by renewable energy.

## Features
- AI model optimization for Edge deployment
- Emissions tracking with **CodeCarbon**
- Real-time performance dashboard for monitoring energy consumption and CO2 emissions

## Requirements
- Python 3.x
- TensorFlow
- PyTorch
- CodeCarbon
